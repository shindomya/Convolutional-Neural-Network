# FeedForward-Neural-Network
##Usability
-This Neural Network is trained on recognizing numbers from the MNIST-Data set
-Comes with already trained weights
-The train.py file trains the network and saves the trained weights and biases
-The test.py file picks a random picture and tries recognizing the number shown on it
-The complete_test.py file goes trough all 10.000 test cases and prints the accuracy of its answers
